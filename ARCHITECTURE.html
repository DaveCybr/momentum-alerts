Momentum Alert Engine

Alat sinyal SMC untuk day trader yang kerja full-time. Rule yang menarik pelatuk, AI yang menerjemahkan, manusia yang memutuskan. Dokumen ini memastikan tiap komponen, alur, dan celah kegagalan punya rumah di arsitektur.

day trader M30/H1 MT5 bridge single process · 3 thread SQLite strategi: smc_top_down AI = narator (P2)
teratasi di desain hanya diungkap / butuh iterasi di luar jangkauan software
Prinsip pengikat
Rule trigger · AI narasiTrigger 100% deterministik & terukur. AI hanya menjelaskan angka yang sudah dihitung — tak pernah menghitung/mengarang harga.
Ship tipisv1 = 1 strategi, 1 pair, tanpa plugin/shadow/AI. Bangun katedral hanya setelah kapelnya jalan.
Jurnal otomatisOutcome di-track sendiri oleh monitor. Beban manusia = 1 tap. Feedback loop selamat dari kemalasan.

04

Strategi: state machine SMC

Alur day-trading owner sebagai urutan berstateful, bukan skor satu candle. State bisa di-rebuild dari replay candle saat boot — tak perlu simpan terpisah.

smc_top_down · liquidity → sweep → POI → konfirmasi
%%{init:{'theme':'dark','themeVariables':{'primaryColor':'#12212b','primaryBorderColor':'#34b8ca','primaryTextColor':'#dfeef2','lineColor':'#5aa6b3','fontFamily':'ui-monospace, monospace'}}}%%
stateDiagram-v2
  [*] --> IDLE
  IDLE --> MAP_LIQUIDITY: bias D1+H4 jelas
  IDLE --> IDLE: ranging (skip)
  MAP_LIQUIDITY --> WAIT_SWEEP: pool ditandai
(EQH/EQL, PDH/PDL, hi/lo sesi)
  WAIT_SWEEP --> ARMED: sweep
(wick tembus + close balik)
  ARMED --> FIND_POI: arah = lawan sweep,
searah HTF
  FIND_POI --> SETUP: tap POI + konfirmasi
(CHoCH / rejection M30·H1)
  SETUP --> [*]: ALERT ✔
  ARMED --> IDLE: timeout / struktur rusak
  FIND_POI --> IDLE: bias flip / invalidasi
Titik subjektif: pilih POI. Mesin nemu SEMUA order block; kamu ambil SATU. Dijembatani skor kualitas POI (fresh · konfluen FVG · nempel level HTF · ukuran wajar), dikalibrasi dari data pilihanmu di Phase 0. Ini area iterasi utama.
05

Tiga gate di dalam evaluate()

Gate A · Regime

Follow the trend

Bias H4 + Daily. Long hanya saat HTF bullish, short saat bearish, ranging → blokir.

VETO KERAS · non-negotiable
Gate B · Momentum

Urutan SMC

Liquidity → sweep → POI → konfirmasi. Inti state machine. Sweep = trigger utama gaya ini.

Gate C · Volume

Pendukung

Konfirmasi partisipasi (tick-volume MT5 / proxy range). Untuk SMC = penguat, bukan syarat mati.

08

Matriks kelengkapan: 9 celah → siapa yang nanganin

Jantung dokumen ini. Tiap mode kegagalan yang kita temukan punya pemilik di arsitektur — atau ditandai jujur sebagai di luar jangkauan software.

#CelahDitangani oleh (arsitektur)Status
1Berhenti isi jurnalAuto-outcome (monitor) + tag 1-tap + digest mingguan di-pushteratasi
2Deteksi ≠ matamuSkor kualitas POI, dikalibrasi dari data pilihanmu Phase 0; tool = subset matamu duluiterasi
3Death spiral kepercayaanAlert engine bias-ke-diam: mulai super ketat, cap harian, cooldown, tierteratasi
4Tetap takut entryEntry zona limit (aktivasi rendah) + track follow-through sebagai datadiungkap saja
5Strategi tak ber-edgeJurnal ukur expectancy setelah spread — angkanya ya angkanyadiungkap saja
6Over-engineeringDisiplin scope v1: 1 strategi · 1 pair · tanpa plugin/shadow/AIteratasi
7Bridge mati diam-diamDead-man's switch (monitor cek heartbeat → teriak "buta")teratasi
8Latency alert telatEntry zona pullback + limit — gaya day-trading tahan latencyteratasi
9AI jadi mesin persuasiAI stub di v1; P2 wajib sebut invalidasi (devil's advocate); AI mati → alert tetap kirimteratasi
Jujur: #4 (takut) & #5 (edge) tak bisa ditutup software apa pun. Tugas tool bukan menyelesaikannya — tapi memberimu kebenaran soal keduanya, yang mana kebanyakan trader tak pernah dapat.
09

Concern lintas-sektor — semua punya rumah

ConcurrencySingle process + 3 thread. Tanpa gunicorn.
Duplikasi sinyalMati by design — tak ada multi-worker. + dedup candle.
Durabilitas stateRebuild dari replay candle saat boot. Tak ada state store terpisah.
Ketahanan dataRantai fallback MT5→TwelveData→yfinance, log sumber.
ObservabilityHeartbeat + dead-man's switch. Senyap ≠ aman.
Jalur backtestGratis dari seam data (BacktestSource, interface sama).
KalibrasiSemua threshold = knob config, dituning lewat jurnal.
Cross-platformWindows (dev) + Linux (Coolify). Tanpa asumsi path Unix.
Deploy1 container, python main.py, Coolify worker, SQLite di volume.
